# Iniruina
Cílem projektu je vytvořit temněji laděnou 2D hru zaměřenou na psychologické zpracování traumatu a silnou atmosféru.
Hráč se v roli mladé dívky ocitá v limbu („mezi životem a smrtí“), kde postupně prochází vzpomínkami a klíčovými traumatickými událostmi své minulosti.
Hlavním prvkem hry není klasický systém odměn, ale emotivní vyprávění příběhu prostoupené environmentálními hádankami a průzkumem prostředí.
